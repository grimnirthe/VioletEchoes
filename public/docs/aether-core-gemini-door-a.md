## Experimental (our mod)

Same family. Same metal. **No iodine.** Changes we actually want judged:

1. Measure think + spend on **the same boule** (not a solar cell next to a memristor).
2. Fuel is **indoor / window light** (200–1000 lux), not AM1.5 as the only number.
3. Switching is **event-driven** — photo-charge accumulates, then a spike. No pack. No 24-hour mechanical hum.
4. Controlled **Br-vacancies** as the think-tracks (iodine-poor does not apply here; say how one actually grows Br-poor CsPbBr₃, or say you do not know).
5. Coat is **Na-free** (ALD Al₂O₃ / SiO₂ / parylene) or bare. No soda-lime.
