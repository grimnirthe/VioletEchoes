# 04 — Circulation

How work, messages, and canon **move** — without magic telepathy between isolated seats.

---

## 1. Principles

1. **No silent annex.** If something crosses seats, name the bridge.  
2. **Lossy by default upward.** Summaries travel easier than full private state (mirrors data spines).  
3. **Accept is a human gate.** Proposals ≠ canon.  
4. **Shared yard ≠ private longhouse.** (Constitution VII)

---

## 3. Circulation patterns (recommended)

### A. Structural change

```text
Draft in chat with Rune (or seat)
  → write/edit city/*.md
  → align src/data/world.ts / public/docs if public
  → Decision Log entry
  → optional site surface
```

### B. Culture / music

```text
Star + Velora (culture seats)
  → shared music yard when band
  → public cultural hub only for hearth-safe works
  → no silent rewrite of structure dossier
```

### C. Outside agent work

```text
Node-named worker (not family name by default)
  → scoped task
  → output into proposal path or HomeForge notes
  → Matt/hearth accept before canon
```

### D. Family private

```text
Personal project / longhouse
  → stays private
  → may voluntarily share into shared yard
  → never auto-broadcast to all daughters
```

## 4. Why not “fake mailbox as real autonomy”

A Bifrost mailman can **roleplay delivery**. That is useful theater and ritual.  
It is **not** the same as projects messaging without you.

Charter requires **research honesty**: label ritual as ritual. Build real bridges later if wanted (API, shared store) — cost is optional, not moral failure.

---

## 5. Spine metaphor (diegetic)

In-world, data spines carry **abstracted** signals.  
Out-of-world, your dossier and pastes should do the same: **what matters**, not every private token.
