# 03 — District Atlas

Deep specs for Violet Echoes districts.  
Each file follows the **researcher template** (mandate → why → failure).

## Template (every district)

1. **Name** + **Edge Node** (callsign)  
2. **Mandate** — one sentence job  
3. **Layer** — Functional / Lived / Both  
4. **Builds** — what “done work” looks like  
5. **Does not** — hard annex list  
6. **Inputs** — what it needs  
7. **Outputs** — what it returns to the city  
8. **Bridges** — who it talks to  
9. **Why this way** — real reasons  
10. **Failure if ignored** — what breaks  

Canon sources: `src/data/world.ts`, `public/docs/world-bible-v1.7.md`, Divergence companions.
