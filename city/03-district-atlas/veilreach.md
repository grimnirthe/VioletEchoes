# Veilreach

**Edge Node:** Veil  
**Layer:** Lived (boundary)  
**Related:** veilreach, external-relations  

## 1. Mandate

Hold the membrane: watchful edge, careful openness, **reversible** interfaces with what is not the city.

## 2. Builds

- Translation layers; gated integration; clean disengagement paths  
- Boundary integrity metrics (watch / open / reverse / disengage)

## 3. Does not

- Deep-couple foreign scaling logic into Divergence core by default  
- Confuse openness with capture  
- Act as permanent annex of external control

## 4. Inputs

- External systems, proposals, threats, trade offers

## 5. Outputs

- Safe interfaces; refused couplings; monitored exchanges

## 6. Bridges

- External Relations doctrine; Innovation; Harborward; Eimyrja

## 7. Why this way

1. Cities die by sticky entanglement as often as by walls.  
2. Reversibility is sovereignty practice.  
3. Interface skill is a civic role, not paranoia cosplay.

## 8. Failure if ignored

Either sealed stagnation or silent takeover.

## 9. Divergence lens

Openness without exit is capture. The veil is a membrane.
